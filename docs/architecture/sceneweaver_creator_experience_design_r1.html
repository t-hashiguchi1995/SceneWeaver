Creator-first information architecture

設定するアプリから、
見ながら決められる制作ツールへ。

現在のSceneWeaverのDomain、Prompt、Generation、CSP、Release基盤を維持したまま、「次に何をするか」「この設定がどう見えるか」「一度だけ試したいときどこへ行くか」を画面から理解できるようにする追加UI/UX設計。

基本方針: Backendの作り直しではない。既存Project / Story / Wardrobe / Shot / Generation Reviewを残し、その上に「制作工程」「視覚辞書」「軽量検証」のレイヤーを追加する。
01

今回解決する課題

順番が分からない

初見ユーザーが「キャラ→セリフ→衣装→Shot」のどこから始めればよいか判断しにくい。

結果を想像しにくい

pose / outfit / lighting / preset が文字列中心で、生成結果の雰囲気が見えにくい。

軽く試せない

本制作フローに入らず「この衣装だけ」「このPromptだけ」を試す短い導線がない。

設計原則

原則従来Creator-first
選択名前・タグサムネイルを見て選び、詳細でPromptを見る
工程機能一覧「次にやること」から工程順に移動
Prompt文字列中心見た目の部品 → 最終Prompt → 詳細設定
セリフテキスト候補コマ上の配置イメージ + 種類 + 文字量
検証Project / Shotが必要Quick Testで1画面完結、良ければ作品へ採用

API追加案

API用途
GET /api/v1/visual-presetsVisual Library一覧。category/tag/model/rating filter。
GET /api/v1/visual-presets/{id}画像、説明、Prompt fragment、関連Preset。
POST /api/v1/quick-tests軽量生成context作成。
POST /api/v1/quick-tests/{id}/render4候補生成。
POST /api/v1/quick-tests/{id}/adopt-to-shot設定をProject/Shotへ移す。
PUT /api/v1/script-events/{id}/presentation-hint吹き出し/ナレーション等の表示ヒント。
GET /api/v1/projects/{id}/workflow-status次工程・未決定項目の集約。

受入条件

IDAcceptance
CX-01Homeから「作品制作」「かんたん検証」「素材を見る」の3目的へ1クリックで移動。
CX-02Project Dashboardだけで次に必要な工程を判断できる。
CX-03衣装 / Pose / Expression / CameraをPrompt文字列を読まずにサンプル画像から選べる。
CX-04Storyでspeech / inner_voice / narration / sfxの違いを仮コマで確認できる。
CX-05Shot Studioで「見た目の部品」と「実際のPrompt」を行き来できる。
CX-06Quick TestはProjectなしで4候補生成まで完了できる。
CX-07Quick Test結果を既存ProjectのShotへ移せる。
CX-08mobileでもVisual Libraryは2列、横overflow 0。
CX-09サンプル画像がreferenceかgeneratedかを識別できる。
CX-10Prompt / provenance / technical IDは必要時に確認できるが通常操作を圧迫しない。

最終イメージ

「振り向きってどんなPose？」
        ↓
Visual Libraryで画像から選ぶ
        ↓
「この衣装と組み合わせたら？」
        ↓
Quick Testで4枚生成
        ↓
良かった設定をShotへ採用
        ↓
Storyのセリフをコマ上で確認
        ↓
Shot Studioで見た目の部品を確認
        ↓
必要ならPromptだけ手編集
        ↓
Generation Reviewで画像を採用
        ↓
CSPへ画像 + セリフ + Presentation Hint
        ↓
仕上げ → Release
目標: Prompt専門知識がなくても「見た目 → 意味 → Prompt」の順で制作できる。一方、必要なユーザーはSeed、Model、Workflowまで降りられる。
