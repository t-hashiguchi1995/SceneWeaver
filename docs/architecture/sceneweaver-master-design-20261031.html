SceneWeaverが保持する差別化

差別化軸価値

7. UI/UX設計原則

Gallery-firstURIやasset://をユーザーへ見せない。
Visual-first文字入力よりサムネイル選択を先にする。
Model abstraction通常ユーザーにはCapability/Profileを見せる。
Explain before generateCharacter / Outfit / Pose / Final Promptを生成前に確認。
Input → Execute → Output → Next全機能で次の行動が明確。
Reuse over recreateHistoryから設定復元。
Human AdoptAgentは提案・生成まで、採用は人。
Visible provenanceseed/model/prompt/pose/outfitを後から確認。

12. Muse / Hermes Agent連携

主体主用途SceneWeaverでの位置
Muse会話しながら創作・Prompt改善・画像相談クリエイティブディレクター
Hermes Agent大量生成、比較、seed/LoRA sweep、検証、反復制作・検証オペレーター
SceneWeaverDomain / 状態 / provenance / approvalSingle Source of Truth
ComfyUI画像生成・編集Workflow実行Execution Engine

MuseCon型の安全設計

Allowed:
- character_id
- outfit_id
- pose_id / pose_view
- capability
- prompt_override / negative_override
- seed / strength / model profile

Not exposed:
- arbitrary node id
- checkpoint filesystem path
- arbitrary raw workflow JSON
- shell command
- unrestricted file access

13. ComfyUI Workflow Registry

Muse Studioの考え方を参考に、ComfyUI workflowを生JSONではなくInput/Output slot付き定義として登録する。

workflow:
  id: anima_pose_v2
  capability: PoseControlledRender
  inputs:
    positive_prompt: {node: 17, field: text}
    pose_image: {node: 32, field: image}
    control_strength: {node: 48, field: strength}
    seed: {node: 12, field: seed}
  outputs:
    image: {node: 91}
  requirements:
    checkpoint: anima_baseV10.safetensors
    control_model: anima-lllite-pose-1.safetensors

万能Workflowを1つ作らず、BaseRender / PoseControlledRender / LayoutGuidedRender / OutfitTryOn / ImageEdit / DetailRepair / Inpaint / Outpaint / Upscale に分ける。

15. 検証Gate再設計

Anima Full Character Coverage

Primary全キャラをGT付きでIdentity / Color / Accessory / Outfit / Silhouette / Overall likeness評価。

Pose Gallery Live P01–P05

ID目的PASS
P01Prompt Posepose_promptが出力へ反映
P02Reference PoseLLLite等で姿勢が寄る
P03Flip左右反転が反映
P04Character isolationPose参考人物が生成Characterへ混ざらない
P05Outfit isolationPose固定で衣装だけ変化

Gate 3 Outfit Isolation

A1 → B → C → A2
- A2がA1と同じOutfitProfile
- prompt snapshotにB/C専用語が残らない
- 画像上でもB/C衣装特徴が残らない
- provenanceでcharacter/outfit/poseを追える

MOSS Quality / Prompt Refine

MOSSも同じSemantic GTで Base caption → Generate → Inspect → Edit → same-seed regenerate → Adopt。基盤PASSと品質PASSを分離する。

Production Fair

同一SemanticをAnima tags / MOSS natural-languageへコンパイルして比較する。
