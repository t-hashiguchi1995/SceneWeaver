スクラップ&ビルドで削るもの

旧Experiment / Trial中心UI

研究用の実行単位を製品UIの中心には置かない。GenerationAttemptは裏の履歴に退避。

巨大な万能Pipeline画面

Dialogue・生成・投稿を1画面/1サービスに詰め込まない。ユーザー行為で画面を分割する。

自作漫画編集ソフト

コマ枠・本格レタリング・ページ編集はCSPに任せる。StudioはHandoffの品質を上げる。

旧プロジェクトから残すのはコードではなく知識： 投稿サイトの実際の操作手順、ComfyUI workflowの動作実績、モデル資産、Eagle運用ノウハウなど。新しいUIやDomainを旧クラス構成に合わせる必要はない。
