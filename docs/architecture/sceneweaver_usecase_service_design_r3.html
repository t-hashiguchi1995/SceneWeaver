SceneWeaver ユースケース駆動サービス設計・UI/検証方針 R3

SceneWeaverの完成判定を「Port/APIがある」から「ユーザーが画面から入力し、実モデルを動かし、結果を確認し、採用・保存・再利用できる」へ変更する。Anima / Qwen / MOSS / 将来のAnime・Adult LoRAはCapability Routerの下で切替・比較する。

1. 完成判定

Gate判定
Domain/API処理・永続化・Capabilityが存在
UI InputID/URI手入力ではなく画面から入力可能
Real ExecutionFakeではなくReal Comfy/実モデルを実行
UI Output生成結果を画面上で確認・比較可能
ContinuationAdopt / Save / Replay / 次工程へ進める
5 Gateすべてを満たして初めて「機能実現済み」とする。

6. R-18

R-18 pipelineは必須。成人として定義したtest characterのみを用い、Project content_rating=adultを明示入口にする。PixAI ratingで自動的にAdultへ切り替えない。

R0 SFW
R1 suggestive
R2 adult nudity
R3 explicit adult expression

Stock MOSSの画質不足は#B FAILにしないが、pipeline failure、General→Adult漏洩、provenance欠落はFAIL。
