v0.2 Sprint 3 UI Addendum

Promptを編集し、
生成結果と実行時Promptを確認するUI

Shot Studioで自動展開されたPrompt Draftを確認・編集し、生成後はGeneration Reviewで候補画像と 「実際にBackendへ送ったPrompt」を1対1で確認する。Prompt Draftはmutable、GenerationAttemptはimmutable snapshotとする。 本書は既存Wireframes R5を置き換えず、Prompt Draft / Generation Review領域の追加仕様として扱う。

01

UI / UX 原則

生成前と生成後を分離

Shot Studioは「何を送るか」を編集する場所。Generation Reviewは「何が出たか」「何を送って出たか」を確認する場所。

表示するPromptに嘘をつかない

Animaがcompiler ruleで生成される場合、存在しないJinjaを見せない。「Anima Compiler v1」を生成元として表示する。

過去生成は不変

現在のPrompt Draftを変更しても、過去GenerationAttemptの画像・Prompt・Seed・Workflow Hashは変化しない。

標準操作: Shot設定 → Prompt Draft確認/編集 → 生成 → 4候補比較 → 実行時Prompt確認 → Adopt / Reject → 必要ならPrompt編集へ戻って再生成。

不採用

同じPrompt Snapshotを使用し、新seedで新Attemptを作る。

Promptを編集して再生成

Shot Studioへ戻り、現在Draftへコピー/再編集して新Attemptを生成する。

06

画面状態 / エラー状態

Draftなし

ShotSpecからPromptDraftを自動作成。「プロンプトを作成中」→編集可能状態。

Draft Fresh

context_hash一致。通常編集・Generate可能。

Draft Modified

BaseとEditedが異なる。「変更あり」を表示。

Draft Stale

context_hash不一致。「再作成 / このまま使用」。silent overwrite禁止。

Generating

queued → running。ボタンを二重送信不可にし、Job進捗へリンク。

Succeeded

Generation Reviewへ遷移。4候補、Prompt Snapshot、provenance。

Failed

エラー分類と再試行導線。Prompt Draftは維持。

Blocked

Comfy offline / model不足。修正導線を表示し、Draftを失わない。

代表エラーメッセージ

内部コードユーザー表示主操作
COMFY_UNREACHABLEComfyUIに接続できません再確認 / 外部連携設定
MODEL_NOT_FOUND必要なモデルが見つかりません診断結果を開く
WORKFLOW_INVALID画像生成ワークフローの設定に問題があります詳細表示
PROMPT_DRAFT_STALEショット設定が変更されています現在設定から再作成 / このまま使用
REBUILD_CONFIRM_REQUIRED編集内容が失われます。再作成しますか？キャンセル / 再作成

Sprint 3 E2Eシナリオ

Shot作成
→ PromptDraft自動生成
→ Positiveに "warm sunset lighting" を追加
→ Generate
→ Generation Reviewへ遷移
→ 候補が4件表示
→ 「実際に使用したPrompt」に編集内容が存在
→ Candidate 2をAdopt
→ Prompt編集へ戻る
→ Draftをさらに変更
→ 再生成
→ 過去AttemptのPrompt Snapshotは変化しない
→ ShotSpec変更
→ PromptDraft staleバナー表示
→ rebuild(confirm=true)
→ 新しいContext HashでDraft更新
合格条件: UI上で「現在編集中のPrompt」と「過去生成時に実際に使ったPrompt」を取り違えないこと。 Generation Reviewは必ずGenerationAttempt snapshotを表示する。

Sprint 3 / Sprint 4 境界

Sprint 3

Shot Studio PromptEditor、Generation Review最小構成、Prompt Snapshot表示、Adopt/Reject、History基礎、Legacy Importer。
