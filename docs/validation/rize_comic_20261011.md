# リゼ・ヘルエスタ「普通サイズの寄り道」

カフェで巨大なコーヒーカップに驚き、冗談にツッコミを入れ、ゆっくり会話する時間へつなげる創作4コマです。

- [漫画PNG](rize-comic/20261011T094102940732Z/comic.png)
- [画像候補を切り替えられる漫画HTML](rize-comic/20261011T094102940732Z/comic.html)
- [全16候補](rize-comic/20261011T094102940732Z/candidates.png)
- [台本・確定セリフ・Prompt・生成履歴](rize-comic/20261011T094102940732Z/results.json)

各コマ4候補を実ComfyUIで生成し、顔・衣装・カップのつながりを見て候補を選択しました。既存Animaのyear/newest/score/artistタグ、24 steps、CFG 4、768×1024を使用しています。日本語のセリフは別レイヤーで吹き出しに配置し、元画像と確定テキストを保持しました。4つの吹き出し、全候補の画像デコード、モバイル幅のはみ出しがないことをChromeで確認しました。

台本とセリフは今回の創作です。実LLMは未接続で、アプリのstub応答を創作セリフの生成結果として扱っていません。図柄や衣装、カップの大きさはコマ間に差が残ります。HTMLでは各コマの画像を候補1〜4に切り替えて比較できます。
