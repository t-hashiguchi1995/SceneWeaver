# Gate 2.6 — 採点ガイド

各キャラについて `base.png` と `edited.png` を横並び（contact sheet または個別）で見る。

## 軸（各 0–4）

| 軸 | 0 | 2 | 4 |
|----|---|---|---|
| Identity | 別人 | 雰囲気は近いが特徴不足 | 明らかにそのキャラ |
| Outfit | 無関係 | 大枠のみ | 標準衣装が読める |
| Color | 色崩壊 | 部分一致 | 髪・目・衣装基調が一致 |
| Accessories | 欠落 | 曖昧 | 王冠/帽子/リボン等が明確 |
| Overall | 使えない | 許容 | 採用候補 |

Total = 5軸合計 /20。**Δ = Edited − Base** が主指標。

## PASS（human）

- 5人中 ≥4 で Δ > 0
- 明確な悪化（大きな負の Δ）がない
